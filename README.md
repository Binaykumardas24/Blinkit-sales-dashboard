# Blinkit-sales-dashboard
# 🛒 Blinkit Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Blinkit Sales Analysis Dashboard** built using Microsoft Power BI to analyze grocery sales performance, product categories, outlet characteristics, and customer ratings.

The dashboard transforms raw grocery data into meaningful insights through KPIs, charts, tables, and interactive filters, helping users understand sales trends and outlet performance.

## 🎯 Project Objectives

- Analyze overall sales performance and average sales.
- Evaluate product performance across different item categories.
- Compare sales by outlet size, location tier, and outlet type.
- Understand the distribution of products by fat content.
- Track outlet establishment trends over time.
- Monitor average customer ratings and item visibility.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Interactive dashboard development
- **Power Query** — Data cleaning and transformation
- **DAX** — KPI calculations and measures
- **Microsoft Excel** — Dataset management

## 📊 Key Performance Indicators (KPIs)

The dashboard displays the following metrics:

- **Total Sales:** $1.2M
- **Average Sales:** $141
- **Number of Items:** 8,523
- **Average Rating:** 3.9

## 📈 Dashboard Features

### 1. Sales Performance Analysis
- Monitored total sales and average sales.
- Analyzed outlet establishment trends from 2011 to 2022.
- Compared sales performance across different outlet types.

### 2. Product Category Analysis
- Compared sales across product categories, including fruits, snacks, household products, frozen foods, and dairy.
- Identified categories contributing the most to total sales.
- Analyzed sales distribution by low-fat and regular-fat products.

### 3. Outlet Performance Analysis
- Compared sales across Tier 1, Tier 2, and Tier 3 locations.
- Analyzed sales distribution by outlet size.
- Evaluated grocery stores and different supermarket types.

### 4. Customer Rating & Product Analysis
- Monitored average product ratings.
- Compared product performance using sales and item counts.
- Examined item visibility across outlet types.

### 5. Interactive Dashboard
- Added filters to explore sales by outlet characteristics.
- Designed KPI cards, bar charts, donut charts, trend lines, and tables.
- Enabled users to explore different aspects of grocery sales performance.

## 🔍 Key Insights

- Total sales reached approximately **$1.2 million**.
- Supermarket Type 1 contributed approximately **$787.5K** in sales.
- Tier 3 outlets recorded approximately **$472.13K** in sales.
- Regular-fat products accounted for approximately **64.6%** of sales, compared with 35.4% for low-fat products.
- The average product rating was **3.9**, indicating the overall rating level shown in the dashboard.
